BUILT FOR OPERATIONS

Fondasi yang jelas untuk setiap transaksi.

Komponen inti disusun agar status pembayaran, proses supplier, dan data transaksi tidak tercampur.

▤

Invoice Engine

Buat invoice dengan kode unik, nominal IDR, metode pembayaran, dan batas waktu. Halaman pelanggan dapat melihat status invoice.

⌁

Webhook terverifikasi

Callback VIPayment divalidasi dengan signature dan pembatasan IP. Status fulfillment supplier tetap terpisah dari pembayaran pelanggan.

◈

Kontrol & keamanan

Secret disimpan di Cloudflare Worker. Database memakai RLS, sementara dashboard admin dibatasi untuk akun pemilik.

FOR DEVELOPERS

Integrasi lewat satu API.

Worker menjadi gerbang server-side antara aplikasi, Supabase, dan callback supplier. Kunci API tidak ditanam di halaman browser.
